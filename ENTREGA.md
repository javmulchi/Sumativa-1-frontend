# Verificación de requisitos — Semana 3

| Criterio de la pauta | Implementación en el proyecto |
|---|---|
| Pantalla de listado (15 pts) | `ProductsPage.jsx`: tabla con código, nombre, marca, categoría, precio y stock. |
| Filtro dinámico (15 pts) | Filtro por categoría y búsqueda; usa `filter()` y `useMemo` sin alterar `state.products`. |
| Pantalla de detalle (15 pts) | `ProductDetailPage.jsx`: ruta dinámica `/productos/:productId`, datos del artículo y selección de cantidad. |
| Modificación del inventario (15 pts) | `inventoryReducer.js`: agregar al carrito descuenta stock; disminuir o quitar devuelve stock; aumentar descuenta stock. |
| Framework CSS (15 pts) | Tailwind CSS 3, diseño responsive y estilos reutilizables con `@apply` en `src/index.css`. |
| Modularidad y reutilización (15 pts) | Separación de páginas, componentes, contexto, reducer, datos, layout y rutas. |
| Publicación en GitHub (10 pts) | README con instrucciones y flujo de GitHub Actions para GitHub Pages. Requiere crear el repositorio y subir el proyecto. |

**Importante:** el último criterio solo se completa cuando el estudiante publica el repositorio y verifica que GitHub Pages esté accesible.
